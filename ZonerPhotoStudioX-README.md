## 📌 What is Zoner Photo Studio X?

Zoner Photo Studio X is an **all-in-one photo management and editing application**, built by Czech developer Zoner Studio since 1993. It merges a fast photo browser/manager, non-destructive RAW development, and full layer-based editing into a single Windows app.

</p>

## ✨ Key Features

| Feature                     | Description                                                    |
| ------------------------------- | ---------------------------------------------------------- |
| Manager module                 | Fast browsing, ratings, keywords, and map-based photo search   |
| Develop module                  | Non-destructive RAW processing with lens corrections             |
| Editor module                   | Full layer-based editing, blend modes, and retouching tools      |
| AI Masking                      | Automatic detection of key elements for instant local edits       |
| Panorama & HDR                  | Built-in stitching and HDR merge tools                            |
| Zonerama Integration             | Direct upload to Zoner's own cloud photo-sharing service          |
| Batch processing                | Apply edits and exports across many photos at once                 |
